# Eve Hayes — Personal Portfolio Website

This repository contains the personal portfolio website for **Eve Hayes**, Program Manager & Operations Leader based in Cape Town, South Africa.

## Overview
- Built with **Next.js** (App Router) and **Tailwind CSS**.
- Designed following clean, executive art direction principles (typography-led, high contrast, responsive).
- Showcases career history, enterprise program governance, operational leadership, core competencies, and featured initiatives.

## Sections
- **Intro / Hero:** Professional headline, background, and quick contact channels.
- **About:** Work ethic, leadership values, and approach to delivery.
- **Work Experience:** Interactive career ledger covering tenure at Achievement Awards Group, Ecentric Payment Systems, and WOW Marketing.
- **Skills & Competencies:** Governance, Operations & Cost Control, People Leadership & Tooling.
- **Featured Initiative:** Writers' Retreat & Hollywood Mentorships (Visionary & Producer).
- **Qualifications:** NQF5 Project Management, Operations Management, Certified Waterfall & Agile.
- **Contact:** Direct links to LinkedIn (`https://www.linkedin.com/in/eve-hayes-2a491122/`), email, and phone.

## Local Development
To run this project locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
